# 🧠 Lung Cancer Image Classification - IEEE Jordan AI Hackathon 1.0

A deep learning project for classifying lung CT images into **Normal**, **Benign**, and **Malignant** categories. Developed for the **IEEE Jordan AI Modeling Hackathon 1.0**, this AI model supports medical professionals in accurate and efficient lung cancer diagnostics.

---

## 🏁 Competition Overview

The IEEE Jordan AI Modeling Hackathon 1.0 challenges participants to tackle a **critical medical imaging problem**:  
> Can AI distinguish between healthy, benign, and malignant lung conditions using only image data?

This project uses **deep learning and computer vision** techniques to create an automated solution for classifying lung medical images, supporting radiologists in making faster, more accurate diagnostic decisions.

---

## 📌 Problem Statement

Lung cancer detection from CT scans is a **time-sensitive and expert-driven task**. By leveraging AI:
- We aim to **reduce diagnostic errors**
- **Speed up the analysis** process
- Improve **early detection and patient outcomes**

Your goal:  
➡️ Build a robust model that classifies lung images into:
- ✅ **Normal** – Healthy lung tissue  
- ⚠️ **Benign** – Non-cancerous nodules or abnormalities  
- ❗ **Malignant** – Cancerous tissue requiring urgent attention  

---

## 🗂️ Dataset Summary

The dataset consists of:
- **Labeled medical images** of lungs
- Three distinct categories: `Normal`, `Benign`, `Malignant`
- High-resolution CT scan images

---

## 🧪 Model Development

Technologies used:
- 🧠 TensorFlow / PyTorch
- 📊 OpenCV / PIL for image preprocessing
- 🔍 CNN, Transfer Learning (e.g., ResNet, EfficientNet)
- 📁 Data augmentation and stratified splitting
